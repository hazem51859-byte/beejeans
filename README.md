## 🎯 نظرة عامة

نظام Bee JEANS هو نظام إدارة متكامل لسلسلة محلات بيع الملابس، يدعم:
- **مخزن رئيسي** واحد يديره الأدمن
- **عدة فروع** يديرها مانجرز وكاشيرات
- **نظام سيريالات** فريد لتتبع كل قطعة
- **إدارة مالية** كاملة مع خزائن وشيفتات
- **تقارير تفصيلية** عن المبيعات والأرباح

---

## ✨ المميزات الرئيسية

### 1. 🏪 إدارة نقاط البيع (POS)
- **مسح سريع للسيريال**: يتم إضافة المنتج للسلة مباشرة عند المسح
- **اختيار المقاس**: dropdown تلقائي لاختيار المقاس عند إضافة المنتج
- **عرض واضح**: cards كبيرة تعرض المنتجات في السلة مع كل التفاصيل
- **طرق دفع متعددة**: نقدي، كارت، أو مختلط
- **طباعة فواتير**: طباعة احترافية مع كل تفاصيل المنتج والمقاس

### 2. 📦 نظام السيريالات
- **تسجيل سيريالات فريدة** لكل قطعة
- **تتبع كامل** للمنتج من الشراء حتى البيع
- **إدارة الحالات**: متاح، مباع، مرتجع
- **استيراد جماعي** من Excel
- **بحث وفلترة** متقدمة

### 3. 🏢 إدارة الفروع والتوريدات
- **توريدات من المخزن الرئيسي** للفروع
- **تتبع حركة المنتجات** بين الفروع
- **استلام وتأكيد** التوريدات
- **تقارير التوريدات** التفصيلية

### 4. 💰 النظام المالي
- **خزائن منفصلة** لكل فرع (نقدي وكارت)
- **إدارة الشيفتات**: فتح وإغلاق مع حساب الفروقات
- **تجريد الدرج**: نقل النقود من الدرج للخزينة
- **معاملات الخزينة**: إيداع، سحب، تحويلات
- **تتبع كامل** لكل الحركات المالية

### 5. 📊 التقارير والإحصائيات
- **تقرير يومي**: ملخص مبيعات اليوم
- **تقرير شهري**: تحليل شامل للشهر
- **تقييم الكاشيرات**: أداء كل كاشير
- **أكثر المنتجات مبيعاً**: مع الألوان والتفاصيل
- **تحليل الأرباح**: بحساب التكاليف الفعلية

### 6. 👥 إدارة المستخدمين
- **ثلاثة أدوار**: أدمن، مانجر، كاشير
- **صلاحيات محددة** لكل دور
- **مستخدمين متعددين** لكل فرع

### 7. 🛍️ إدارة المنتجات
- **منتجات بتفاصيل كاملة**: اسم، لون، مقاس، سعر
- **أصناف وفئات** منظمة
- **إدارة المخزون** الفوري
- **تنبيهات نفاذ المخزون**

### 8. 🤝 إدارة الشركاء والعملاء
- **نظام الشركاء**: موردين ومصنعين
- **نظام العملاء**: عملاء الجملة
- **فواتير الشراء**: من الموردين
- **فواتير البيع**: للعملاء
- **إدارة المدفوعات**: سداد ومتحصلات

## 🛠️ التقنيات المستخدمة

### Backend
- **Node.js** + **Express.js**: RESTful API
- **Prisma ORM**: إدارة قاعدة البيانات
- **SQLite**: قاعدة بيانات محلية
- **JWT**: نظام المصادقة والتوكينات
- **Socket.io**: تحديثات فورية (Real-time)

### Frontend
- **React 18**: مكتبة UI
- **Vite**: Build Tool سريع
- **React Router v6**: التنقل بين الصفحات
- **TanStack Query**: إدارة الحالة والبيانات
- **Zustand**: State Management
- **Tailwind CSS**: التصميم والأنماط
- **Lucide React**: الأيقونات
- **React Hot Toast**: الإشعارات
- **Day.js**: التعامل مع التواريخ

## 🚀 التثبيت والإعداد

### 1. تحميل المشروع

```bash
git clone <repository-url>
cd Abdelrahman
```

### 2. تثبيت Backend

```bash
cd backend
npm install
```

### 3. إعداد قاعدة البيانات

```bash
# إنشاء قاعدة البيانات
npx prisma generate
npx prisma migrate dev

# تعبئة البيانات الأولية
npx prisma db seed
```

### 4. تثبيت Frontend

```bash
cd ../frontend-pos
npm install
```

### 5. تشغيل المشروع

**في terminal منفصل للـ Backend:**
```bash
cd backend
npm start
# أو
node src/server.js
```

**في terminal منفصل للـ Frontend:**
```bash
cd frontend-pos
npm run dev
```

### 6. فتح التطبيق

- **Frontend**: `http://localhost:5173`
- **Backend API**: `http://localhost:5000/api/v1`

### 👨‍💼 دليل الأدمن

#### 1. إضافة منتجات جديدة

**الطريقة الأولى: يدوياً**
1. اذهب إلى **"المنتجات والسيريالات"**
2. اضغط **"إضافة منتج جديد"**
3. املأ البيانات:
   - الاسم
   - الصنف
   - اللون والمقاس (اختياري)
   - سعر الشراء (للأدمن فقط)
   - سعر البيع
4. احفظ المنتج
5. أضف سيريالات:
   - اكتب السيريال أو امسحه
   - اضغط **"تسجيل السيريال"**

**الطريقة الثانية: استيراد جماعي من Excel**
1. حضر ملف Excel بالأعمدة التالية:
   ```
   Name | Category | SKU | Serial | Color | Size | CostPrice | SellingPrice
   ```
2. في صفحة **"المنتجات والسيريالات"**
3. اضغط **"استيراد من Excel"**
4. اختر الملف
5. راجع البيانات واضغط **"تأكيد الاستيراد"**

#### 2. إدارة الفروع

1. اذهب إلى **"الفروع"**
2. أضف فرع جديد بالمعلومات:
   - الاسم
   - الكود (اختياري)
   - الحالة (نشط/غير نشط)
3. يتم إنشاء خزينة تلقائياً لكل فرع

#### 3. توريد منتجات للفروع

1. اذهب إلى **"التوريدات"**
2. اضغط **"توريد جديد"**
3. اختر:
   - الفرع المستلم
   - الصنف
   - المنتجات
4. أضف السيريالات (بالمسح أو الكتابة)
5. راجع المنتجات والأسعار
6. اضغط **"تأكيد التوريد"**

#### 4. مراقبة الخزائن

1. اذهب إلى **"الخزينة"**
2. شاهد أرصدة كل الفروع:
   - الخزينة النقدية
   - خزينة الكارت
   - الإجمالي
3. شاهد سجل المعاملات

#### 5. التقارير

**التقرير الشهري الشامل:**
1. اذهب إلى **"التقرير الشهري"**
2. اختر الشهر والسنة
3. شاهد:
   - ملخص المبيعات
   - المشتريات من الموردين
   - المصروفات
   - تحليل الأرباح
   - أداء الفروع
   - مبيعات العملاء
4. اضغط **"طباعة التقرير"** للطباعة

**تقرير المنتجات الأكثر مبيعاً:**
1. اذهب إلى **"التقارير"**
2. حدد الفترة الزمنية
3. شاهد قائمة أكثر 10 منتجات مبيعاً

**تقييم الكاشيرات:**
1. اذهب إلى **"تقييم الكاشيرات"**
2. شاهد أداء كل كاشير:
   - عدد المبيعات
   - إجمالي الإيرادات
   - متوسط قيمة الفاتورة

---

### 👔 دليل المانجر

#### 1. فتح الشيفت للكاشير

1. اذهب إلى **"الإعدادات"**
2. في قسم **"الكاشيرات والشيفتات"**
3. اختر الكاشير
4. اضغط **"فتح شيفت"**
5. أدخل الرصيد الافتتاحي (الفلوس في الدرج)

#### 2. إغلاق شيفت الكاشير

1. في **"الإعدادات"**
2. اختر الشيفت المفتوح
3. اضغط **"إغلاق الشيفت"**
4. أدخل المبلغ الفعلي في الدرج (بعد العد)
5. النظام يحسب الفرق تلقائياً

#### 3. تجريد الدرج (نقل الفلوس للخزينة)

1. اذهب إلى **"إدارة الشيفتات"**
2. شاهد الشيفتات المغلقة
3. اختر الشيفت
4. اضغط **"تجريد الدرج"**
5. أدخل المبلغ الفعلي
6. اضغط **"نقل للخزينة"**
7. الفلوس تنتقل من الدرج لخزينة الفرع

#### 4. إدارة الخزينة

1. اذهب إلى **"الخزينة"**
2. شاهد الرصيد الحالي
3. إيداع نقود:
   - اضغط **"إيداع نقدي"**
   - أدخل المبلغ والوصف
4. سحب نقود:
   - اضغط **"سحب نقدي"**
   - أدخل المبلغ والسبب

#### 5. استلام التوريدات

1. اذهب إلى **"التوريدات"**
2. ستجد التوريدات المنتظرة من المخزن الرئيسي
3. راجع التوريد
4. اضغط **"استلام التوريد"**
5. المنتجات تضاف لمخزون الفرع

---

### 💳 دليل الكاشير

#### 1. فتح الشيفت

1. عند تسجيل الدخول، اذهب إلى **"الإعدادات"**
2. في قسم **"الشيفت"**
3. إذا لم يكن عندك شيفت مفتوح:
   - المانجر يفتح لك الشيفت
   - ستشاهد إشعار "لديك شيفت مفتوح"

#### 2. البيع من نقطة البيع

1. اذهب إلى **"نقطة البيع"**
2. **امسح السيريال** باستخدام الماسح
3. **اختر المقاس** من القائمة التي تظهر تلقائياً
4. المنتج يضاف للسلة مع كل تفاصيله:
   - الاسم
   - اللون
   - المقاس
   - السيريال
   - السعر
5. كرر لكل المنتجات
6. راجع السلة (في الجانب الأيسر)
7. اختر طريقة الدفع:
   - **نقدي**: أدخل المبلغ المدفوع، النظام يحسب الباقي
   - **كارت**: المبلغ كامل بالكارت
   - **مختلط**: جزء نقدي وجزء كارت
8. اضغط **"إتمام البيع"**
9. **اطبع الفاتورة** تلقائياً

#### 3. عرض المنتجات المتاحة

1. اذهب إلى **"منتجاتي"**
2. شاهد كل المنتجات المتاحة في مخزون فرعك
3. يمكنك البحث والفلترة حسب:
   - الاسم
   - اللون
   - الحالة (متاح، مباع، مرتجع)

#### 4. مراجعة المخزون

1. اذهب إلى **"المخزون"**
2. شاهد:
   - المنتجات المتاحة
   - المنتجات المباعة
   - المنتجات المرتجعة
   - تنبيهات نفاذ المخزون

#### 5. الفواتير والمبيعات

1. اذهب إلى **"الفواتير"**
2. حدد الفترة الزمنية
3. شاهد كل الفواتير مع:
   - رقم الفاتورة
   - التاريخ والوقت
   - الإجمالي
   - طريقة الدفع
4. اضغط على أي فاتورة لرؤية التفاصيل الكاملة

#### 6. إغلاق الشيفت

1. في نهاية اليوم، اذهب إلى **"الإعدادات"**
2. اعد الفلوس في الدرج
3. اضغط **"إغلاق الشيفت"**
4. أدخل المبلغ الفعلي
5. اضغط **"تأكيد الإغلاق"**
6. انتظر المانجر لتجريد الدرج

## ⚙️ الإعدادات المتقدمة

### تغيير البورت

**Backend (.env):**
```env
PORT=5000
```

**Frontend (vite.config.js):**
```javascript
export default defineConfig({
  server: {
    port: 5173
  }
})
```

### Rate Limiting

في ملف `.env` في الـ Backend:
```env
RATE_LIMIT_WINDOW_MS=60000    # دقيقة واحدة
RATE_LIMIT_MAX_REQUESTS=100000 # عدد الطلبات المسموحة
```

### JWT Tokens

في ملف `.env` في الـ Backend:
```env
JWT_SECRET=your-secret-key-here
JWT_EXPIRES_IN=7d
```

## 🐛 حل المشاكل الشائعة

### المشكلة: "Cannot connect to database"
**الحل:**
```bash
cd backend
npx prisma generate
npx prisma migrate dev
```

### المشكلة: "Port already in use"
**الحل:**
- غير البورت في `.env` أو `vite.config.js`
- أو أوقف البروسيس القديم

### المشكلة: "Module not found"
**الحل:**
```bash
# احذف node_modules وأعد التثبيت
rm -rf node_modules
npm install
```

### المشكلة: الماسح لا يعمل
**الحل:**
- تأكد أن الماسح في وضع "Keyboard Emulation"
- اضبطه ليضيف Enter في نهاية كل مسح
